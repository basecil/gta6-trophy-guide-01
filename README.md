An offline, single-page GTA VI trophy guide for the [GTA 6 Trophy Guide](https://make.fun/bounty/gta6-trophy-guide-01) bounty — all 55 official trophies with own-words guides and per-trophy sources, a five-stage platinum roadmap with progress, a missables page, a Next-up planner, PSN counters, per-trophy notes, a spoiler-safe setting, localStorage save with JSON export/import, keyboard shortcuts and three themes. No build step, no network, system fonts only.

Competition entry: https://make.fun/bounty/gta6-trophy-guide-01

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.

## Features

- All 55 official trophies, each with an own-words guide and its sources.
- Five-stage platinum roadmap that tracks progress stage by stage.
- Missables page listing every trophy that can be locked out, with when to do it.
- Next-up planner: the next trophy, the queue ordered missables first, and the closest counters.
- PSN counters for the grindy trophies, with per-trophy notes.
- Spoiler-safe setting that hides story details.
- localStorage save with JSON export and import.
- Keyboard shortcuts, including a full shortcut list.
- Three themes: Night, Midnight and Parchment.
